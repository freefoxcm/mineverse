# MineVerse 实施计划（已批准）

> 目标：从零构建浏览器版 Minecraft 核心复刻，完成 M0–M5 开发与全量验证，M6 发布到 GitHub Pages `https://freefoxcm.github.io/mineverse/`。
> 本文件是给全体 teammate 的规格摘要；接口与协作规则以 `docs/CONTRACTS.md` 为准。基线状态：M0 完成（渲染/扁平世界/HUD/截图链路），单测 35 绿。

## 1. 范围

**一期做**：生存闭环（挖掘/合成/熔炉/箱子/饥饿/生命/护甲/掉落/死亡重生）、创造模式（飞行/无限方块/即时破坏/创造物品栏）、8 种生物与战斗、无限地形/生物群系/洞穴/矿脉、光照与 AO、昼夜/天空/雾/水下、程序化像素素材与音效、IndexedDB 存档、完整 UI、调试 API、单元 + E2E + 截图验证。
**一期不做**：多人、红石、下界/末地、村民/交易、附魔/经验、农耕、船/矿车、楼梯/半砖/门、天气、移动端、官方素材/音乐、GitHub Actions 自动部署。

## 2. 技术决策

- WebGL2 + Three.js 0.186 + TypeScript strict + Vite 8；无 UI 框架（DOM/CSS）。
- 区块 16×16×160（10 段 16³），海平面 63；无限水平；确定性种子。
- 20 TPS 固定步长 + 渲染插值；主线程渲染/物理/AI，Worker 做世界生成与网格化。
- 纹理：WebGL2 纹理数组，每 tile 32×32，逐面 layer，NearestMipmapLinear；程序化原创美术。
- 存档 IndexedDB（`mineverse/worlds`），字符串 palette + edits 增量；导出/导入 JSON。
- GitHub Pages：`main` 源码、`gh-pages` 构建产物、Vite `base: './'`、本地 `pnpm deploy` 脚本。

**玩家参数**：AABB 0.6×1.8、眼高 1.62、潜行 1.5；步行 4.317 / 疾跑 5.612 / 潜行 1.295 / 飞行 10.89 m/s；重力 32 m/s²、跳跃初速 8.9；触及 5；摔落伤害 floor(落差-3)；护甲每点 4%（≤80%）；受击无敌 0.5s；昼夜 24000 tick。

## 3. 核心系统

### 3.1 世界/区块/流式
- 列内索引 `(y<<8)|(z<<4)|x`；blocks/meta/sky/blockLight 各 40960 字节；heightMap 256。
- 以玩家为中心螺旋加载/卸载；RD 4–12（默认 8），加载范围 RD+1、网格需四邻居就绪、卸载 RD+2。
- 生成 worker 池 + 网格 worker 池（各 3–4 个，`navigator.hardwareConcurrency-2`），transferable，jobId/version 丢弃过期。
- 存档 edits 在卸载时入队落盘。

### 3.2 地形（M1）
- 高度：`64 + 18*fbm(1/180) + 14*ridged(1/90) + 6*fbm(1/28)` 按大陆度/侵蚀度调制，钳制 4–150；海平面 63，近水 2 格沙滩。
- 群系：温度/湿度噪声 + 高度 → 平原/森林/白桦林/针叶林/沙漠/雪原/山地/海洋/沙滩；控制树种、草/叶 tint、植被、积雪/冰。
- 洞穴：3D 芝士洞 + 意面洞（y<56）；y<10 填岩浆。
- 矿：煤 5–120、铜 5–80、铁 5–64、金 5–32、红石 5–16、青金石 5–30、钻石 5–16，避免替换空气/水。
- 基岩 0–2 锯齿；树木/仙人掌/花/甘蔗按 3×3 邻域确定性裁剪，跨区块无缝。
- 出生点：0,0 半径 64 内找非水草地，生成/光照完成前冻结物理。

### 3.3 光照（M1）
- 天光 0–15：列顶向下不衰减，横向 BFS 衰减 1；方块光：火把 14/熔炉 13/岩浆 15。
- 跨区块传播进已加载邻列，未加载记录 pending；拆/放方块局部移除+重播种，脏段合并网格。
- 顶点：四邻平均 + AO 四角；面明暗顶 1.0/侧 0.62,0.8/底 0.48（现有实现）。
- 渲染合成：`max(blockRGB*blockLight, skyRGB*skyLight*daylight)` × tint × AO。

### 3.4 网格/渲染（M0 已有，M1 完善）
- 三种层：opaque / cutout(alpha discard，双面) / transparent(混合、无深度写)。
- cube 六面裁切、cross 双交叉、torch 小盒、liquid 表面高度；同类透明块剔除。
- 顶点格式：position/uv/layer/lights(sky,block ×17)/shade(AO×面明暗)/tint(RGB)；索引 0,1,2 0,2,3。
- 天空：渐变穹顶、日月、星空、云层；雾色取地平线；水下滤色。
- 第一人称手持独立场景；实体方块模型 + 动画；粒子 billboard；选中框 + 10 帧裂纹。

### 3.5 玩家/物理/交互（M2）
- 逐轴 swept AABB，重力/跳跃/疾跑/潜行/游泳/岩浆/飞行；渲染位置插值。
- 指针锁、灵敏度、FOV 疾跑拉伸、±90° 视角、创造双击空格飞行。
- DDA 射线（触及 5）返回方块/法线/距离；破坏公式：`硬度 × (正确工具?1.5:5) / 工具速度`；工具耐久；放置朝向/可替换/碰撞内禁止/支撑检查；右键使用/吃/点火/拉弓。
- 掉落物实体、拾取吸附、裂纹动画、粒子、音效，TNT 点燃。

### 3.6 物品/合成/容器（M3）
- 9 快捷栏 + 27 背包 + 4 护甲；左右键拿放/取半、Shift 快速转移、数字键交换、Q 丢弃；满包处理。
- 配方：有序 pattern+key（自动偏移、不镜像）+ 无序；2×2/3×3 共用匹配器；≥70 条；配方书面板。
- 熔炉：输入/燃料/输出、10s、燃料表、点燃发光+进度；箱子 27 格；方块实体持久化。
- 堆叠 64（工具/护甲 1）、耐久条、tooltip。

### 3.7 生存/战斗（M2+M3）
- 生命 20/饥饿 20/饱和度/消耗度；疾跑/跳跃/挖掘消耗；≥18 缓慢回血；0 饥饿掉血；和平难度不刷怪。
- 伤害源：摔落/溺水/岩浆/近战/箭/爆炸；护甲减伤；死亡掉物品、死亡界面、重生。
- 0.5s 受击无敌、击退、暴击、弓箭蓄力/弹道/伤害衰减。

### 3.8 生物（M4）
| 生物 | HP | 行为 | 伤害 | 掉落 |
|---|---|---|---|---|
| 僵尸 | 20 | 追击近战、白天着火 | 3 | 腐肉、稀有铁锭 |
| 骷髅 | 20 | 保持距离射箭、走位、白天着火 | 2–4 | 骨头、箭 |
| 苦力怕 | 20 | 潜行接近、1.5s 引信、膨胀 | 爆炸 | 火药 |
| 蜘蛛 | 16 | 快速追击、跳跃、白天中立 | 2 | 线 |
| 猪/牛/羊/鸡 | 10/10/8/4 | 闲逛、受击逃跑 | 0 | 肉、皮革、羊毛、羽毛 |

- 通用：重力/AABB/液体减速、状态机、3D A*（≤300 节点/0.5s）+ 视线、跳 1 格、避水/岩浆、128m 消失、上限敌对 24/被动 12。
- 刷怪：敌对 24–48m 光照≤7 固体地面；被动草地光照≥9；难度影响。
- 爆炸：球体射线按抗性破坏、伤害衰减+击退；苦力怕威力 3、TNT 4；粒子/音效/震屏。
- 掉落物：旋转浮动、5 分钟消失、拾取入背包。

### 3.9 UI/音频/存档/命令
- 界面：标题、世界列表、创建世界、加载、HUD、暂停、设置、F3、聊天/命令、背包、工作台、熔炉、箱子、创造物品栏、死亡、WebGL 错误页、操作说明。
- HUD：红心（半心）、饥饿、护甲、氧气、快捷栏/选中框/数量/耐久、准星、受伤红晕、水下滤色、toast、手持物品。
- 设置：渲染距离、FOV、灵敏度、音量、云、像素比、显示 FPS；localStorage。
- 音频：WebAudio 程序化 ~24 种，首次手势解锁，无音乐。
- 存档 schema v1（字段见 CONTRACTS/计划）：meta/player/time/palette/edits/blockEntities；自动保存 60s + 暂停/退出；Quota 提示 + 导出 JSON。
- 命令：`/help /seed /time set day|night|ticks /gamemode survival|creative /tp x y z /give item [n] /kill /clear /spawnpoint`。
- 调试 API：`window.__MC__`（ready/metrics/getBlock/setBlock/teleport/look/createWorld/loadWorld/save/openScreen/spawnMob/explode/commands/errors）。
